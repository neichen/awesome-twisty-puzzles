# Awesome Twisty Puzzles

Daftar pilihan situs web, alat, dan sumber belajar untuk speedcubing dan teka-teki putar (twisty puzzles) lainnya.

Daftar ini adalah titik awal bagi siapa pun yang ingin mempelajari suatu metode, mengukur waktu penyelesaian, mencari algoritma, menggunakan pemecah atau simulator, atau membaca matematika di balik teka-teki ini. Daftar ini tidak terbatas pada kubus 3×3.

Daftar ini dimulai dari [awesome-rubiks-cube](https://github.com/nirajpandkar/awesome-rubiks-cube) oleh [Niraj Pandkar](https://github.com/nirajpandkar), yang dirilis di bawah [CC0 1.0](LICENSE). Entri dari daftar itu diperiksa ulang; tautan yang mati atau diparkir dihapus, URL yang berpindah diperbarui, dan daftar ini diperluas.

**Pengungkapan:** Pemelihara daftar ini adalah penulis [Cube Solver Lab](https://cube-solver.org/), yang tercantum di bawah [Pemecah](#pemecah).

Sebagian besar sumber yang ditautkan berbahasa Inggris.

## Resmi dan kompetisi

- [World Cube Association](https://www.worldcubeassociation.org/) - Organisasi yang mengatur kompetisi speedcubing resmi dan memublikasikan hasilnya.
- [WCA Competitions](https://www.worldcubeassociation.org/competitions) - Kalender kompetisi resmi yang akan datang dan yang telah berlangsung.
- [WCA Live](https://live.worldcubeassociation.org/) - Situs resmi untuk memasukkan dan mengikuti hasil kompetisi secara langsung.
- [WCA Regulations](https://www.worldcubeassociation.org/regulations/) - Peraturan dan pedoman resmi untuk kompetisi WCA.
- [WCA Results Export](https://www.worldcubeassociation.org/export/results) - Ekspor publik dari basis data hasil resmi WCA.
- [Cubing.com (粗饼)](https://cubing.com/) - Situs kompetisi cubing asal Tiongkok, dengan daftar kontes dan hasilnya.
- [Rubik's](https://rubiks.com/) - Situs resmi merek Rubik's, termasuk panduan penyelesaian untuk pemula.

- [Speedsolving Wiki](https://www.speedsolving.com/wiki/) - Ensiklopedia komunitas tentang metode, algoritma, nomor, dan istilah.
- [ZZ method (wiki)](https://www.speedsolving.com/wiki/index.php/ZZ_Method) - Artikel Speedsolving Wiki tentang metode ZZ.

## Algoritma dan rekonstruksi

- [333.fm](https://333.fm/) - Situs latihan fewest moves dengan pencari sisipan (proyek yang sama dengan fewestmov.es).
- [CubeDB](https://cubedb.net/) - Basis data algoritma dan kumpulan rekonstruksi penyelesaian.
- [Nissy](https://nissy.tronto.net/) - Pemecah kubus dan asisten fewest moves.
- [SpeedCubeDB](https://speedcubedb.com/) - Basis data algoritma yang dapat dicari untuk banyak nomor dan langkah WCA.

## Timer

- [csTimer](https://cstimer.net/) - Timer di browser untuk nomor WCA, dengan statistik, alat sesi, dan masukan perangkat keras opsional.
- [CubeDesk](https://www.cubedesk.io/) - Timer di browser dengan fitur latihan dan pertandingan daring.
- [CubeTimer](https://cubetimer.com/) - Timer kubus daring yang sederhana.
- [CubingTime](https://cubingtime.com/timer) - Timer speedcubing daring dengan fitur kontes.
- [qqTimer](https://qqtimer.net/) - Timer ringan di browser yang dioperasikan dengan papan ketik.
- [Ruwix CubeTimer](https://ruwix.com/online-rubiks-stopwatch-timer/) - Timer kubus daring dengan grafik performa.

## Pemecah

- [Cube Explorer](https://kociemba.org/cube.htm) - Program Herbert Kociemba untuk menyelesaikan dan menganalisis kubus 3×3 dengan algoritma dua fase.
- [Cube Solver Lab](https://cube-solver.org/) - Pemecah sumber terbuka di browser untuk kubus 2×2–15×15, Pyraminx, Skewb, dan Megaminx, dengan pemutaran langkah demi langkah dalam 3D dan graf permutasi.
- [Ruwix Cube Solver](https://ruwix.com/cube-solver/) - Pemecah kubus 3×3 daring.

## Simulator dan kubus virtual

- [alg.cubing.net](https://alg.cubing.net/) - Penampil algoritma dan rekonstruksi, sekaligus pemutar kubus virtual.
- [AnimCubeJS](https://animcubejs.cubing.net/) - Simulator animasi kubus di browser, diport dari AnimCube karya Josef Jelinek.
- [cubing.net](https://www.cubing.net/) - Direktori cubing.js, Twizzle, dan alat terkait.
- [Ruwix Simulators](https://ruwix.com/simulators/) - Simulator di browser untuk kubus 3×3 dan teka-teki putar lainnya.
- [Twizzle](https://alpha.twizzle.net/) - Pemutar teka-teki, penyunting algoritma, dan penampil rekonstruksi yang dibuat dengan cubing.js.
- [VisualCube](https://cube.rider.biz/visualcube.php) - API gambar untuk menghasilkan diagram kubus (Conrad Rider).

## Pustaka perangkat lunak

- [cubing.js](https://js.cubing.net/cubing/) - Pustaka JavaScript untuk geometri teka-teki, notasi algoritma, scramble, dan penampil `<twisty-player>`. Sumber: [cubing/cubing.js](https://github.com/cubing/cubing.js).
- [gullicube](https://github.com/rokicki/gullicube) - Pemecah umum karya Tomas Rokicki untuk kubus NxN yang besar.
- [min2phase](https://github.com/cs0x7f/min2phase) - Implementasi teroptimasi dari algoritma dua fase Kociemba, dipakai oleh beberapa timer dan pengacak.
- [RubiksCube-TwophaseSolver](https://github.com/hkociemba/RubiksCube-TwophaseSolver) - Pemecah dua fase Python karya Herbert Kociemba.
- [TNoodle](https://github.com/thewca/tnoodle) - Program scramble resmi WCA.
- [twips](https://github.com/cubing/twips) - Twizzle Pattern Searcher, program untuk mencari algoritma dan scramble pada teka-teki putar (sebelumnya twsearch).
