# Awesome Twisty Puzzles

一份面向速解以及其他異形魔術方塊（twisty puzzles）的網站、工具和學習資源精選列表。

本列表適合想學習公式套路、為復原計時、查找公式、使用解題器或模擬器，或了解相關數學的人。內容不限於三階魔術方塊。

本列表以 [awesome-rubiks-cube](https://github.com/nirajpandkar/awesome-rubiks-cube) 為起點，由 [Niraj Pandkar](https://github.com/nirajpandkar) 發布，採用 [CC0 1.0](LICENSE) 授權。我們重新檢查了其中的條目，刪除了失效或被停放的連結，更新了已遷移的網址，並擴充了內容。

**揭露：** 本列表的維護者是 [Cube Solver Lab](https://cube-solver.org/) 的作者，該專案列在[解題器](#解題器)一節。

多數連向的外部資源為英文。

## 官方與比賽

- [World Cube Association](https://www.worldcubeassociation.org/) - 負責管理官方速解比賽並公布成績的組織。
- [WCA Competitions](https://www.worldcubeassociation.org/competitions) - 即將舉行和已經舉辦的官方比賽日程。
- [WCA Live](https://live.worldcubeassociation.org/) - 登錄並追蹤比賽現場成績的官方網站。
- [WCA Regulations](https://www.worldcubeassociation.org/regulations/) - WCA 比賽的正式規則與指南。
- [WCA Results Export](https://www.worldcubeassociation.org/export/results) - 官方 WCA 成績資料庫的公開匯出。
- [Cubing.com (粗饼)](https://cubing.com/) - 中國魔術方塊賽事網站，提供比賽資訊與成績。
- [Rubik's](https://rubiks.com/) - Rubik's 品牌官網，含入門復原教學。

## 學習與教程

- [CFOP Discussion](https://www.speedsolving.com/threads/cfop-discussion.6085/) - SpeedSolving.com 上討論如何用 CFOP 提高成績的長期求助討論串。
- [CFOP method (wiki)](https://www.speedsolving.com/wiki/index.php/CFOP) - Speedsolving Wiki 上關於 CFOP（Fridrich）方法的條目。
- [CubeMastery](https://cubemastery.com/rubiks-cube-tutorial-step-by-step/) - 面向初學者的三階魔術方塊分步復原教學。
- [CubeSkills](https://www.cubeskills.com/) - Feliks Zemdegs 提供的教學與公式資源。
- [How to Solve a Rubik's Cube (Part One)](https://www.youtube.com/watch?v=HsQIoPyfQzM) - Dan Brown 的入門影片教學。
- [J Perm](https://jperm.net/) - 速解教學與公式表。
- [Petrus method (wiki)](https://www.speedsolving.com/wiki/index.php/Petrus_Method) - Speedsolving Wiki 上關於 Petrus 方法的條目。
- [Roux method (wiki)](https://www.speedsolving.com/wiki/index.php/Roux_Method) - Speedsolving Wiki 上關於 Roux 方法的條目。
- [Rubik's 3×3 Solve Guide](https://rubiks.com/solve-guide) - 官方三階魔術方塊入門復原指南。
- [Ruwix](https://ruwix.com/) - 介紹魔術方塊記號、種類與復原方法的參考網站。
- [Ruwix Beginner's Method](https://ruwix.com/the-rubiks-cube/how-to-solve-the-rubiks-cube-beginners-method/) - 層先法入門教學。
- [Ruwix CFOP](https://ruwix.com/the-rubiks-cube/advanced-cfop-fridrich/) - CFOP（Fridrich）方法概覽。
- [Speedsolving Wiki](https://www.speedsolving.com/wiki/) - 收錄方法、公式、項目和術語的社群百科。
- [ZZ method (wiki)](https://www.speedsolving.com/wiki/index.php/ZZ_Method) - Speedsolving Wiki 上關於 ZZ 方法的條目。

## 公式與還原復盤

- [333.fm](https://333.fm/) - 最少步練習網站，含插入尋找工具（與 fewestmov.es 為同一專案）。
- [CubeDB](https://cubedb.net/) - 公式資料庫與復原復盤合集。
- [Nissy](https://nissy.tronto.net/) - 魔術方塊解題器與最少步輔助工具。
- [SpeedCubeDB](https://speedcubedb.com/) - 可檢索的公式資料庫，涵蓋多項 WCA 項目與步驟。

## 計時器

- [csTimer](https://cstimer.net/) - 用於 WCA 項目的瀏覽器計時器，帶統計、分組工具，並可選用硬體輸入。
- [CubeDesk](https://www.cubedesk.io/) - 帶訓練功能和線上對戰的瀏覽器計時器。
- [CubeTimer](https://cubetimer.com/) - 簡潔的線上魔術方塊計時器。
- [CubingTime](https://cubingtime.com/timer) - 帶比賽功能的線上速解計時器。
- [qqTimer](https://qqtimer.net/) - 輕量、可用鍵盤操作的瀏覽器計時器。
- [Ruwix CubeTimer](https://ruwix.com/online-rubiks-stopwatch-timer/) - 帶成績曲線的線上魔術方塊計時器。

## 解題器

- [Cube Explorer](https://kociemba.org/cube.htm) - Herbert Kociemba 用於解題和分析三階魔術方塊的程式，採用兩階段演算法。
- [Cube Solver Lab](https://cube-solver.org/) - 開源的瀏覽器解題器，支援 2×2–15×15 魔術方塊、金字塔、斜轉和五魔方，帶分步 3D 回放和置換圖。
- [Ruwix Cube Solver](https://ruwix.com/cube-solver/) - 線上三階魔術方塊解題器。

## 模擬器與虛擬魔術方塊

- [alg.cubing.net](https://alg.cubing.net/) - 公式與復盤檢視器，兼虛擬魔術方塊播放器。
- [AnimCubeJS](https://animcubejs.cubing.net/) - 瀏覽器中的魔術方塊動畫模擬器，移植自 Josef Jelinek 的 AnimCube。
- [cubing.net](https://www.cubing.net/) - cubing.js、Twizzle 及相關工具的目錄。
- [Ruwix Simulators](https://ruwix.com/simulators/) - 三階及其他異形魔術方塊的瀏覽器模擬器。
- [Twizzle](https://alpha.twizzle.net/) - 基於 cubing.js 的謎題播放器、公式編輯器和復盤檢視器。
- [VisualCube](https://cube.rider.biz/visualcube.php) - 用於產生魔術方塊示意圖的影像介面（Conrad Rider）。

## 軟體庫

- [cubing.js](https://js.cubing.net/cubing/) - 用於謎題幾何、公式記號、打亂以及 `<twisty-player>` 檢視器的 JavaScript 函式庫。 原始碼：[cubing/cubing.js](https://github.com/cubing/cubing.js)。
- [gullicube](https://github.com/rokicki/gullicube) - Tomas Rokicki 面向高階 NxN 魔術方塊的通用解題器。
- [min2phase](https://github.com/cs0x7f/min2phase) - Kociemba 兩階段演算法的優化實作，被若干計時器和打亂程式使用。
- [RubiksCube-TwophaseSolver](https://github.com/hkociemba/RubiksCube-TwophaseSolver) - Herbert Kociemba 的 Python 兩階段解題器。
- [TNoodle](https://github.com/thewca/tnoodle) - 官方 WCA 打亂程式。
- [twips](https://github.com/cubing/twips) - Twizzle Pattern Searcher，用於在異形魔術方塊上查找公式和打亂（前稱 twsearch）。

- [Jaap's Puzzle Page](https://www.jaapsch.net/puzzles/) - 異形與機械益智玩具百科，含解法與數學筆記。

- [The Two-Phase Algorithm](https://kociemba.org/twophase.htm) - Kociemba 對三階兩階段解題演算法的說明。
