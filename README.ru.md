# Awesome Twisty Puzzles

Подборка сайтов, инструментов и учебных материалов по спидкубингу и другим твисти-головоломкам.

Этот список — отправная точка для тех, кто хочет выучить метод, засекать сборки, искать алгоритмы, пользоваться солвером или симулятором либо почитать о математике этих головоломок. Он не ограничен кубиком 3×3.

Этот список начат на основе [awesome-rubiks-cube](https://github.com/nirajpandkar/awesome-rubiks-cube) автора [Niraj Pandkar](https://github.com/nirajpandkar), опубликованного на условиях [CC0 1.0](LICENSE). Записи исходного списка были перепроверены: нерабочие и «припаркованные» ссылки удалены, переехавшие адреса обновлены, список расширен.

**Раскрытие информации:** Составитель этого списка — автор [Cube Solver Lab](https://cube-solver.org/), проект указан в разделе [Солверы](#солверы).

Большинство связанных ресурсов — на английском языке.

## Официальное и соревнования

- [World Cube Association](https://www.worldcubeassociation.org/) - Организация, которая проводит официальные соревнования по спидкубингу и публикует результаты.
- [WCA Competitions](https://www.worldcubeassociation.org/competitions) - Календарь предстоящих и прошедших официальных соревнований.
- [WCA Live](https://live.worldcubeassociation.org/) - Официальный сайт для ввода и просмотра результатов соревнований в прямом эфире.
- [WCA Regulations](https://www.worldcubeassociation.org/regulations/) - Официальные правила и рекомендации для соревнований WCA.
- [WCA Results Export](https://www.worldcubeassociation.org/export/results) - Открытый экспорт официальной базы результатов WCA.
- [Cubing.com (粗饼)](https://cubing.com/) - Китайский сайт кубических соревнований со списком турниров и результатами.
- [Rubik's](https://rubiks.com/) - Официальный сайт бренда Rubik's, в том числе с руководствами для начинающих.

## Обучение и руководства

- [CFOP Discussion](https://www.speedsolving.com/threads/cfop-discussion.6085/) - Давно действующая тема помощи на SpeedSolving.com о прогрессе в методе CFOP.
- [CFOP method (wiki)](https://www.speedsolving.com/wiki/index.php/CFOP) - Статья Speedsolving Wiki о методе CFOP (Fridrich).
- [CubeMastery](https://cubemastery.com/rubiks-cube-tutorial-step-by-step/) - Пошаговое руководство для начинающих по сборке кубика 3×3.
- [CubeSkills](https://www.cubeskills.com/) - Учебные материалы и алгоритмы от Феликса Земдегса (Feliks Zemdegs).
- [How to Solve a Rubik's Cube (Part One)](https://www.youtube.com/watch?v=HsQIoPyfQzM) - Обучающее видео для начинающих от Дэна Брауна (Dan Brown).
- [J Perm](https://jperm.net/) - Уроки по спидкубингу и таблицы алгоритмов.
- [Petrus method (wiki)](https://www.speedsolving.com/wiki/index.php/Petrus_Method) - Статья Speedsolving Wiki о методе Petrus.
- [Roux method (wiki)](https://www.speedsolving.com/wiki/index.php/Roux_Method) - Статья Speedsolving Wiki о методе Roux.
- [Rubik's 3×3 Solve Guide](https://rubiks.com/solve-guide) - Официальное руководство для начинающих по сборке кубика 3×3.
- [Ruwix](https://ruwix.com/) - Справочный сайт о нотации, видах головоломок и методах сборки.
- [Ruwix Beginner's Method](https://ruwix.com/the-rubiks-cube/how-to-solve-the-rubiks-cube-beginners-method/) - Руководство по методу для начинающих (слой за слоем).
- [Ruwix CFOP](https://ruwix.com/the-rubiks-cube/advanced-cfop-fridrich/) - Обзор метода CFOP (Fridrich).
- [Speedsolving Wiki](https://www.speedsolving.com/wiki/) - Сообщественная энциклопедия методов, алгоритмов, дисциплин и терминов.
- [ZZ method (wiki)](https://www.speedsolving.com/wiki/index.php/ZZ_Method) - Статья Speedsolving Wiki о методе ZZ.

## Алгоритмы и реконструкция

- [333.fm](https://333.fm/) - Сайт для практики сборки на наименьшее число ходов со средством поиска вставок (тот же проект, что fewestmov.es).
- [CubeDB](https://cubedb.net/) - База алгоритмов и коллекция реконструкций сборок.
- [Nissy](https://nissy.tronto.net/) - Солвер кубика и помощник для сборки на наименьшее число ходов.
- [SpeedCubeDB](https://speedcubedb.com/) - Поисковая база алгоритмов для многих дисциплин и этапов WCA.

## Таймеры

- [csTimer](https://cstimer.net/) - Браузерный таймер для дисциплин WCA, со статистикой, инструментами сессий и необязательным вводом с оборудования.
- [CubeDesk](https://www.cubedesk.io/) - Браузерный таймер с тренировочными функциями и онлайн-матчами.
- [CubeTimer](https://cubetimer.com/) - Простой онлайн-таймер для кубика.
- [CubingTime](https://cubingtime.com/timer) - Онлайн-таймер для спидкубинга с функциями для конкурсов.
- [qqTimer](https://qqtimer.net/) - Лёгкий браузерный таймер с управлением с клавиатуры.
- [Ruwix CubeTimer](https://ruwix.com/online-rubiks-stopwatch-timer/) - Онлайн-таймер для кубика с графиком результатов.

## Солверы

- [Cube Explorer](https://kociemba.org/cube.htm) - Программа Херберта Коцембы (Herbert Kociemba) для сборки и анализа кубика 3×3 двухфазным алгоритмом.
- [Cube Solver Lab](https://cube-solver.org/) - Открытый браузерный солвер для кубиков 2×2–15×15, пирамидки, скьюба и мегаминкса, с пошаговым 3D-воспроизведением и графом перестановок.
- [Ruwix Cube Solver](https://ruwix.com/cube-solver/) - Онлайн-солвер кубика 3×3.

## Симуляторы и виртуальные кубики

- [alg.cubing.net](https://alg.cubing.net/) - Просмотр алгоритмов и реконструкций, а также проигрыватель виртуального кубика.
- [AnimCubeJS](https://animcubejs.cubing.net/) - Браузерный симулятор анимации кубика, перенесённый с AnimCube Йозефа Елинка (Josef Jelinek).
- [cubing.net](https://www.cubing.net/) - Каталог cubing.js, Twizzle и связанных инструментов.
- [Ruwix Simulators](https://ruwix.com/simulators/) - Браузерные симуляторы кубика 3×3 и других твисти-головоломок.
- [Twizzle](https://alpha.twizzle.net/) - Проигрыватель головоломок, редактор алгоритмов и просмотр реконструкций на основе cubing.js.
- [VisualCube](https://cube.rider.biz/visualcube.php) - API изображений для генерации схем кубика (Conrad Rider).

## Программные библиотеки

- [cubing.js](https://js.cubing.net/cubing/) - Библиотека JavaScript для геометрии головоломок, нотации алгоритмов, скрамблов и просмотрщика `<twisty-player>`. Исходный код: [cubing/cubing.js](https://github.com/cubing/cubing.js).
- [gullicube](https://github.com/rokicki/gullicube) - Универсальный солвер Томаса Рокицки (Tomas Rokicki) для больших кубиков NxN.
- [min2phase](https://github.com/cs0x7f/min2phase) - Оптимизированная реализация двухфазного алгоритма Коцембы, которую используют несколько таймеров и генераторов скрамблов.
- [RubiksCube-TwophaseSolver](https://github.com/hkociemba/RubiksCube-TwophaseSolver) - Двухфазный солвер Херберта Коцембы на Python.
- [TNoodle](https://github.com/thewca/tnoodle) - Официальная программа скрамблов WCA.
- [twips](https://github.com/cubing/twips) - Twizzle Pattern Searcher — программа для поиска алгоритмов и скрамблов на твисти-головоломках (ранее twsearch).

## Математика и теория

- [God's Number is 20](https://cube20.org/) - Материалы о доказательстве того, что любую позицию 3×3 можно собрать не более чем за 20 ходов в метрике полуоборотов.
- [Jaap's Puzzle Page](https://www.jaapsch.net/puzzles/) - Энциклопедия твисти- и механических головоломок, с решениями и математическими заметками.
- [Kociemba's Homepage](https://kociemba.org/) - Сайт Херберта Коцембы, включая Cube Explorer и описание двухфазного алгоритма.
- [The Two-Phase Algorithm](https://kociemba.org/twophase.htm) - Описание Коцембой двухфазного алгоритма сборки 3×3.
