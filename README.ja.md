# Awesome Twisty Puzzles

スピードキュービングやその他のツイストパズル向けのウェブサイト、ツール、学習リソースを集めたリストです。

解法を覚えたい人、タイムを測りたい人、アルゴリズムを調べたい人、ソルバーやシミュレーターを使いたい人、パズルの背後にある数学を読みたい人のための出発点です。3×3 キューブに限りません。

このリストは、[awesome-rubiks-cube](https://github.com/nirajpandkar/awesome-rubiks-cube) を出発点にしています。[Niraj Pandkar](https://github.com/nirajpandkar) が [CC0 1.0](LICENSE) で公開したものです。掲載項目を再確認し、リンク切れやドメインパークされたものは外し、移転した URL を更新したうえで内容を拡充しました。

**開示：** このリストのメンテナーは [Cube Solver Lab](https://cube-solver.org/) の作者であり、同プロジェクトは[ソルバー](#ソルバー)に掲載しています。

リンク先のリソースの多くは英語です。

## 公式と大会

- [World Cube Association](https://www.worldcubeassociation.org/) - 公式スピードキュービング大会を統括し、記録を公開している組織です。
- [WCA Competitions](https://www.worldcubeassociation.org/competitions) - 今後の公式大会と過去の大会のカレンダーです。
- [WCA Live](https://live.worldcubeassociation.org/) - 大会のライブ結果を入力・閲覧するための公式サイトです。
- [WCA Regulations](https://www.worldcubeassociation.org/regulations/) - WCA 大会の公式ルールとガイドラインです。
- [WCA Results Export](https://www.worldcubeassociation.org/export/results) - 公式 WCA 記録データベースの公開エクスポートです。
- [Cubing.com (粗饼)](https://cubing.com/) - 中国のキュービング大会サイトで、大会情報と結果を掲載しています。
- [Rubik's](https://rubiks.com/) - Rubik's ブランドの公式サイトで、初心者向けの解法ガイドもあります。

## 学習とチュートリアル

- [CFOP Discussion](https://www.speedsolving.com/threads/cfop-discussion.6085/) - CFOP で速くなることをテーマにした、SpeedSolving.com の長年続いているヘルプスレッドです。
- [CFOP method (wiki)](https://www.speedsolving.com/wiki/index.php/CFOP) - CFOP（Fridrich）法についての Speedsolving Wiki の記事です。
- [CubeMastery](https://cubemastery.com/rubiks-cube-tutorial-step-by-step/) - 3×3 キューブを解くための、初心者向けの手順解説です。
- [CubeSkills](https://www.cubeskills.com/) - Feliks Zemdegs によるチュートリアルとアルゴリズム資料です。
- [How to Solve a Rubik's Cube (Part One)](https://www.youtube.com/watch?v=HsQIoPyfQzM) - Dan Brown による初心者向けの動画解説です。
- [J Perm](https://jperm.net/) - スピードキュービングの解説とアルゴリズム表です。
- [Petrus method (wiki)](https://www.speedsolving.com/wiki/index.php/Petrus_Method) - Petrus 法についての Speedsolving Wiki の記事です。
- [Roux method (wiki)](https://www.speedsolving.com/wiki/index.php/Roux_Method) - Roux 法についての Speedsolving Wiki の記事です。
- [Rubik's 3×3 Solve Guide](https://rubiks.com/solve-guide) - 3×3 キューブの公式な初心者向け解法ガイドです。
- [Ruwix](https://ruwix.com/) - パズルの表記、種類、解法をまとめた参考サイトです。
- [Ruwix Beginner's Method](https://ruwix.com/the-rubiks-cube/how-to-solve-the-rubiks-cube-beginners-method/) - 層ごとに揃える初心者向け解法の解説です。
- [Ruwix CFOP](https://ruwix.com/the-rubiks-cube/advanced-cfop-fridrich/) - CFOP（Fridrich）法の概要です。
- [Speedsolving Wiki](https://www.speedsolving.com/wiki/) - 解法、アルゴリズム、種目、用語をまとめたコミュニティの百科事典です。
- [ZZ method (wiki)](https://www.speedsolving.com/wiki/index.php/ZZ_Method) - ZZ 法についての Speedsolving Wiki の記事です。

## アルゴリズムと再現

- [333.fm](https://333.fm/) - 最少手数の練習サイトで、インサーション検索機能があります（fewestmov.es と同じプロジェクトです）。
- [CubeDB](https://cubedb.net/) - アルゴリズムのデータベースと、ソルブ再現のコレクションです。
- [Nissy](https://nissy.tronto.net/) - キューブソルバー兼最少手数の補助ツールです。
- [SpeedCubeDB](https://speedcubedb.com/) - 多くの WCA 種目とステップを対象にした、検索可能なアルゴリズムデータベースです。

## タイマー

- [csTimer](https://cstimer.net/) - WCA 種目向けのブラウザタイマーで、統計、セッション機能、任意のハードウェア入力に対応しています。
- [CubeDesk](https://www.cubedesk.io/) - 練習機能とオンライン対戦のあるブラウザタイマーです。
- [CubeTimer](https://cubetimer.com/) - シンプルなオンラインキューブタイマーです。
- [CubingTime](https://cubingtime.com/timer) - コンテスト機能のあるオンラインのスピードキュービングタイマーです。
- [qqTimer](https://qqtimer.net/) - キーボード操作の軽量なブラウザタイマーです。
- [Ruwix CubeTimer](https://ruwix.com/online-rubiks-stopwatch-timer/) - 成績グラフ付きのオンラインキューブタイマーです。

## ソルバー

- [Cube Explorer](https://kociemba.org/cube.htm) - Herbert Kociemba による、2 フェーズアルゴリズムで 3×3 キューブを解いて解析するプログラムです。
- [Cube Solver Lab](https://cube-solver.org/) - 2×2〜15×15 のキューブ、ピラミンクス、スキューブ、メガミンクスに対応したオープンソースのブラウザソルバーです。手順を 3D で再生でき、置換グラフもあります。
- [Ruwix Cube Solver](https://ruwix.com/cube-solver/) - オンラインの 3×3 キューブソルバーです。

## シミュレーターと仮想キューブ

- [alg.cubing.net](https://alg.cubing.net/) - アルゴリズムや再現を表示し、仮想キューブを再生できるビューアです。
- [AnimCubeJS](https://animcubejs.cubing.net/) - Josef Jelinek の AnimCube を移植した、ブラウザ上のキューブアニメーションシミュレーターです。
- [cubing.net](https://www.cubing.net/) - cubing.js、Twizzle、関連ツールのディレクトリです。
- [Ruwix Simulators](https://ruwix.com/simulators/) - 3×3 キューブなどツイストパズルのブラウザシミュレーターです。
- [Twizzle](https://alpha.twizzle.net/) - cubing.js を使ったパズルプレイヤー、アルゴリズムエディタ、再現ビューアです。
- [VisualCube](https://cube.rider.biz/visualcube.php) - キューブの図を生成する画像 API です（Conrad Rider）。

## ソフトウェアライブラリ

- [cubing.js](https://js.cubing.net/cubing/) - パズルの幾何、アルゴリズム表記、スクランブル、`<twisty-player>` ビューア向けの JavaScript ライブラリです。 ソース：[cubing/cubing.js](https://github.com/cubing/cubing.js)。
- [gullicube](https://github.com/rokicki/gullicube) - Tomas Rokicki による、大きな NxN キューブ向けの汎用ソルバーです。
- [min2phase](https://github.com/cs0x7f/min2phase) - Kociemba の 2 フェーズアルゴリズムの最適化実装で、いくつかのタイマーやスクランブラーが利用しています。
- [RubiksCube-TwophaseSolver](https://github.com/hkociemba/RubiksCube-TwophaseSolver) - Herbert Kociemba による Python の 2 フェーズソルバーです。
- [TNoodle](https://github.com/thewca/tnoodle) - WCA の公式スクランブルプログラムです。
- [twips](https://github.com/cubing/twips) - ツイストパズルのアルゴリズムやスクランブルを探すプログラム Twizzle Pattern Searcher です（旧称 twsearch）。

## 数学と理論

- [God's Number is 20](https://cube20.org/) - ハーフターン計量では、どの 3×3 の配置も最大 20 手で解けるという証明の背景を紹介しています。
- [Jaap's Puzzle Page](https://www.jaapsch.net/puzzles/) - ツイストパズルや機械式パズルの百科で、解法と数学的なメモがあります。
- [Kociemba's Homepage](https://kociemba.org/) - Herbert Kociemba のサイトで、Cube Explorer と 2 フェーズアルゴリズムの説明があります。
- [The Two-Phase Algorithm](https://kociemba.org/twophase.htm) - 3×3 を解く 2 フェーズアルゴリズムについての、Kociemba 自身による解説です。
