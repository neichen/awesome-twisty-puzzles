# Awesome Twisty Puzzles

一份面向速拧以及其他异形魔方（twisty puzzles）的网站、工具和学习资源精选列表。

本列表适合想学习公式套路、给复原计时、查找公式、使用求解器或模拟器，或了解相关数学的人。内容不限于三阶魔方。

本列表以 [awesome-rubiks-cube](https://github.com/nirajpandkar/awesome-rubiks-cube) 为起点，由 [Niraj Pandkar](https://github.com/nirajpandkar) 发布，采用 [CC0 1.0](LICENSE) 授权。我们重新检查了其中的条目，删除了失效或被停放的链接，更新了已迁移的地址，并扩充了内容。

**披露：** 本列表的维护者是 [Cube Solver Lab](https://cube-solver.org/) 的作者，该项目列在[求解器](#求解器)一节。

多数链向的外部资源为英文。

## 官方与比赛

- [World Cube Association](https://www.worldcubeassociation.org/) - 负责管理官方速拧比赛并公布成绩的组织。
- [WCA Competitions](https://www.worldcubeassociation.org/competitions) - 即将举行和已经举办的官方比赛日程。
- [WCA Live](https://live.worldcubeassociation.org/) - 录入并跟踪比赛现场成绩的官方网站。
- [WCA Regulations](https://www.worldcubeassociation.org/regulations/) - WCA 比赛的正式规则与指南。
- [WCA Results Export](https://www.worldcubeassociation.org/export/results) - 官方 WCA 成绩数据库的公开导出。
- [Cubing.com (粗饼)](https://cubing.com/) - 中国魔方赛事网站，提供比赛信息与成绩。
- [Rubik's](https://rubiks.com/) - Rubik's 品牌官网，含入门复原教程。

## 学习与教程

- [CFOP Discussion](https://www.speedsolving.com/threads/cfop-discussion.6085/) - SpeedSolving.com 上讨论如何用 CFOP 提高成绩的长期求助帖。

- [CubeSkills](https://www.cubeskills.com/) - Feliks Zemdegs 提供的教程与公式资源。
- [How to Solve a Rubik's Cube (Part One)](https://www.youtube.com/watch?v=HsQIoPyfQzM) - Dan Brown 的入门视频教程。
- [J Perm](https://jperm.net/) - 速拧教程与公式表。
- [Petrus method (wiki)](https://www.speedsolving.com/wiki/index.php/Petrus_Method) - Speedsolving Wiki 上关于 Petrus 方法的条目。
- [Roux method (wiki)](https://www.speedsolving.com/wiki/index.php/Roux_Method) - Speedsolving Wiki 上关于 Roux 方法的条目。
- [Rubik's 3×3 Solve Guide](https://rubiks.com/solve-guide) - 官方三阶魔方入门复原指南。
- [Ruwix](https://ruwix.com/) - 介绍魔方记号、种类与复原方法的参考网站。
- [Ruwix Beginner's Method](https://ruwix.com/the-rubiks-cube/how-to-solve-the-rubiks-cube-beginners-method/) - 层先法入门教程。
- [Ruwix CFOP](https://ruwix.com/the-rubiks-cube/advanced-cfop-fridrich/) - CFOP（Fridrich）方法概览。
- [Speedsolving Wiki](https://www.speedsolving.com/wiki/) - 收录方法、公式、项目和术语的社区百科。
- [ZZ method (wiki)](https://www.speedsolving.com/wiki/index.php/ZZ_Method) - Speedsolving Wiki 上关于 ZZ 方法的条目。

## 公式与还原复盘

- [333.fm](https://333.fm/) - 最少步练习网站，含插入查找工具（与 fewestmov.es 为同一项目）。
- [CubeDB](https://cubedb.net/) - 公式数据库与复原复盘合集。
- [Nissy](https://nissy.tronto.net/) - 魔方求解器与最少步辅助工具。
- [SpeedCubeDB](https://speedcubedb.com/) - 可检索的公式数据库，覆盖多项 WCA 项目与步骤。

## 计时器

- [csTimer](https://cstimer.net/) - 用于 WCA 项目的浏览器计时器，带统计、分组工具，并可选用硬件输入。
- [CubeDesk](https://www.cubedesk.io/) - 带训练功能和在线对战的浏览器计时器。
- [CubeTimer](https://cubetimer.com/) - 简洁的在线魔方计时器。
- [CubingTime](https://cubingtime.com/timer) - 带比赛功能的在线速拧计时器。
- [qqTimer](https://qqtimer.net/) - 轻量、可用键盘操作的浏览器计时器。
- [Ruwix CubeTimer](https://ruwix.com/online-rubiks-stopwatch-timer/) - 带成绩曲线的在线魔方计时器。

## 求解器

- [Cube Explorer](https://kociemba.org/cube.htm) - Herbert Kociemba 用于求解和分析三阶魔方的程序，采用两阶段算法。
- [Cube Solver Lab](https://cube-solver.org/) - 开源的浏览器求解器，支持 2×2–15×15 魔方、金字塔、斜转和五魔方，带分步 3D 回放和置换图。
- [Ruwix Cube Solver](https://ruwix.com/cube-solver/) - 在线三阶魔方求解器。

## 模拟器与虚拟魔方

- [alg.cubing.net](https://alg.cubing.net/) - 公式与复盘查看器，兼虚拟魔方播放器。
- [AnimCubeJS](https://animcubejs.cubing.net/) - 浏览器中的魔方动画模拟器，移植自 Josef Jelinek 的 AnimCube。
- [cubing.net](https://www.cubing.net/) - cubing.js、Twizzle 及相关工具的目录。
- [Ruwix Simulators](https://ruwix.com/simulators/) - 三阶及其他异形魔方的浏览器模拟器。
- [Twizzle](https://alpha.twizzle.net/) - 基于 cubing.js 的谜题播放器、公式编辑器和复盘查看器。
- [VisualCube](https://cube.rider.biz/visualcube.php) - 用于生成魔方示意图的图像接口（Conrad Rider）。

## 软件库

- [cubing.js](https://js.cubing.net/cubing/) - 用于谜题几何、公式记号、打乱以及 `<twisty-player>` 查看器的 JavaScript 库。 源码：[cubing/cubing.js](https://github.com/cubing/cubing.js)。
- [gullicube](https://github.com/rokicki/gullicube) - Tomas Rokicki 面向高阶 NxN 魔方的通用求解器。
- [min2phase](https://github.com/cs0x7f/min2phase) - Kociemba 两阶段算法的优化实现，被若干计时器和打乱程序使用。
- [RubiksCube-TwophaseSolver](https://github.com/hkociemba/RubiksCube-TwophaseSolver) - Herbert Kociemba 的 Python 两阶段求解器。
- [TNoodle](https://github.com/thewca/tnoodle) - 官方 WCA 打乱程序。
- [twips](https://github.com/cubing/twips) - Twizzle Pattern Searcher，用于在异形魔方上查找公式和打乱（前称 twsearch）。

- [God's Number is 20](https://cube20.org/) - 关于「在半周转度量下，任意三阶局面至多 20 步可解」这一证明的背景说明。
- [Jaap's Puzzle Page](https://www.jaapsch.net/puzzles/) - 异形与机械谜题百科，含解法与数学笔记。
- [Kociemba's Homepage](https://kociemba.org/) - Herbert Kociemba 的网站，含 Cube Explorer 及两阶段算法说明。
- [The Two-Phase Algorithm](https://kociemba.org/twophase.htm) - Kociemba 对三阶两阶段求解算法的说明。
